# GridSim v3.3.7

发布日期：2026-08-18

## 高级操作

- 新增仅管理员可见的「高级操作」页面。
- 支持修改当前管理员密码，密码配置采用原子替换方式保存。
- 支持清理 SQLite 历史数据库，操作前 Flush 异步写队列并备份数据库。
- 支持删除全部业务配置，清空实例、趋势模板、代理配置和业务文件。
- 所有破坏性操作均要求有效的 admin JWT、当前密码和精确确认词。
- 配置删除保留 `users.json`、`db/`、`backups/` 和 `py_simulator/`，备份保存到运行目录外侧的 `backups/admin-ops/`。
- 后端新增独立 `AdminMiddleware`，不依赖前端隐藏菜单实现权限控制。

## 升级注意事项

升级前仍需备份运行目录中的 `config/`。高级操作只能由确认过影响范围的管理员执行，数据库清理与业务配置删除是两个独立操作。
