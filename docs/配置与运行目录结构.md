# GridSim 配置与运行目录结构

## 目录职责

运行目录将「可编辑配置」「运行时数据」「日志」「静态资源」分开。配置目录由 `--config-dir` 指定，日志目录由 `--log-dir` 指定，SQLite 数据库默认位于配置目录下的 `db/`。

```text
GridSim/
├─ bin/
│  └─ gridsim(.exe)                 # 程序文件
├─ web/dist/                        # 前端静态资源
├─ resources/                       # 内置 API 测试资源，只读
├─ config/                          # --config-dir：可备份的业务配置
│  ├─ instances.json                # 实例配置
│  ├─ users.json                    # 登录用户配置
│  ├─ trends/
│  │  └─ templates.json             # 共享趋势模板，由 Web API 管理
│  ├─ auto_changes/
│  │  └─ <instance_id>.json         # 实例自动变化策略
│  ├─ db/
│  │  ├─ gridsim.db                 # 测点历史滚动数据
│  │  ├─ gridsim.db-wal             # SQLite 运行时文件
│  │  └─ gridsim.db-shm             # SQLite 运行时文件
│  ├─ point-table-backups/<id>/      # 点表替换前的备份
│  ├─ recordings/                    # 接口操作录制文件
│  ├─ csv/                           # CSV 回放文件
│  └─ *.xlsx                         # 点表及共享测试数据
└─ logs/                             # --log-dir：运行日志，不与配置混放
   ├─ output.log                    # 启动脚本重定向的管理进程日志
   └─ <instance_id>-<port>/
      ├─ instance.log               # 实例日志
      └─ instance.log.0~3           # 实例日志滚动文件
```

## 趋势模板配置

趋势模板不再依赖浏览器 `localStorage`，保存到：

```text
config/trends/templates.json
```

文件使用版本化包装结构，便于后续迁移：

```json
{
  "version": 1,
  "templates": [
    {
      "id": "station-a",
      "name": "变电站 A",
      "panels": [
        {
          "kind": "collection",
          "trace_configs": [
            {
              "inst_id": "abc123",
              "inst": "实例 A",
              "ioa": 16385,
              "name": "有功功率",
              "unit": "kW",
              "alias": "",
              "color_idx": 0,
              "point_type": "AI"
            }
          ]
        }
      ],
      "created_at": 1787050000000,
      "updated_at": 1787050000000
    }
  ]
}
```

前端的「覆盖保存」「另存为」「删除」分别调用模板 API，后端对模板名称、面板类型、测点实例 ID 和数量进行校验，并使用临时文件写入后替换正式文件，避免进程中断时留下半份 JSON。

旧版本已经写入 `localStorage` 的 `trend_templates` 会在首次打开趋势页时自动迁移。迁移成功后删除旧缓存；服务端暂不可用时保留兼容副本，不影响当前页面继续查看。

## 数据边界

- **共享模板**：放在服务端配置文件，适合跨浏览器、跨用户使用。
- **当前工作区**：`trend_panels` 仍保留在浏览器本地，用于保存当前浏览器的临时面板、布局和未保存编辑，不会覆盖其他浏览器的工作区。
- **测点历史**：放在 `config/db/gridsim.db`，按现有保留期滚动清理，不与模板 JSON 混合。
- **实例日志**：由 `--log-dir` 管理。此前 `--log-dir` 只创建目录但实例日志仍写入 `config/logs` 的问题已修正。

## 启动示例

```text
# Windows
bin\gridsim.exe serve --config-dir config --log-dir logs --http :8989

# Linux
bin/gridsim serve --config-dir ./config --log-dir ./logs --http :8989
```

配置目录建议整体备份；日志和 `config/db/` 可按运维保留策略单独清理。删除趋势模板只影响模板配置，不会删除测点历史数据。
