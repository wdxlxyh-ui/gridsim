## 1. 需求概述

在 Python 微电网模拟器的电表（Meter）设备上增加**电网频率（Frequency）**测点，支持 **4 种频率仿真模式**：

| 模式编号 | 名称 | 说明 |
|---------|------|------|
| 0 | 下垂模型 (Droop) | 基于功率平衡的物理下垂特性计算，频率随负荷变化 |
| 1 | 固定值 (Fixed) | 固定频率 + 小幅随机噪声，适合只需要有值的场景 |
| 2 | 可配置目标值 (Configurable) | 从 device.json 读取目标频率，支持运行时通过 Modbus 写入修改 |
| 3 | CSV 回放 (CSV Replay) | 从 CSV 文件回放频率数据，线性插值，支持 24 小时周期 |

通过 `device.json` 中 Meter 设备的 `frequency_mode` 参数切换模式。

## 3. 四种频率模式详细设计

### 3.1 模式 0：下垂模型 (Droop)

**物理原理**：电网频率与功率平衡直接相关。负荷超过发电时频率下降，发电超过负荷时频率上升。

**计算公式**：

```
frequency = f_nominal + deviation + noise

其中：
  f_nominal       = 50.0 Hz（额定频率）
  deviation       = -total_power × droop_coefficient
  droop_coefficient = 0.001 Hz/kW（每 kW 不平衡偏移量）
  noise           = random(-0.02, +0.02) Hz
  限幅            = [49.5, 50.5] Hz
```

**行为特征**：
- `total_power > 0`（净消耗，从电网取电）→ 频率下降
- `total_power < 0`（净发电，向电网送电）→ 频率上升
- 适合需要观察频率与负荷联动关系的测试场景

**配置参数**：

| 参数 | JSON Key | 默认值 | 说明 |
|------|----------|--------|------|
| 额定频率 | nominal_frequency | 50.0 | Hz |
| 下垂系数 | frequency_droop | 0.001 | Hz/kW |
| 噪声幅度 | frequency_noise | 0.02 | Hz |

---

### 3.2 模式 1：固定值 (Fixed)

**行为**：输出固定的额定频率值，叠加极小随机波动模拟真实电网。

**计算公式**：

```
frequency = f_nominal + random(-0.05, +0.05)
```

**适用场景**：只需要频率测点有合理值，不关心与功率的联动关系。

**配置参数**：

| 参数 | JSON Key | 默认值 | 说明 |
|------|----------|--------|------|
| 额定频率 | nominal_frequency | 50.0 | Hz |

---

### 3.3 模式 2：可配置目标值 (Configurable)

**行为**：从 device.json 读取目标频率作为初始值，运行时支持通过 Modbus FC16 写入新的目标频率值，实现外部控制。

**计算公式**：

```
frequency = target_frequency + random(-noise, +noise)

target_frequency 初始值来自 device.json 配置
运行时可通过 Modbus 写入寄存器地址 4 修改 target_frequency
```

**适用场景**：需要外部系统（如 EMS）下发频率设定值进行联调测试。

**配置参数**：

| 参数 | JSON Key | 默认值 | 说明 |
|------|----------|--------|------|
| 目标频率 | target_frequency | 50.0 | Hz，可运行时写入 |
| 噪声幅度 | frequency_noise | 0.01 | Hz |

**Modbus 写入**：通过 FC16 写入 Meter 设备的寄存器偏移地址 4（FrequencySetpoint），值自动更新为新的目标频率。

---

### 3.4 模式 3：CSV 回放 (CSV Replay)

**行为**：从指定的 CSV 文件读取 24 小时频率时间序列，根据当前仿真时刻线性插值输出。

**CSV 文件格式**：

```csv
小时,频率(Hz)
0.0,50.02
0.25,50.01
0.5,49.98
...
23.75,50.03
24.0,50.02
```

- 第一行为表头（自动跳过）
- 步长 0.25 小时（15 分钟），中间值线性插值
- 值域应在 49.0~51.0 Hz 范围（不做强制校验）

**适用场景**：回放真实录波数据、模拟频率事件（如低频减载）。

**配置参数**：

| 参数 | JSON Key | 默认值 | 说明 |
|------|----------|--------|------|
| CSV 文件 | frequency_csv_file | "" | 相对于 config/ 目录 |

#### 6.1.2 电表模型 — `src/models/meter_model.py`

完整重写，支持 4 种模式：

```python
import logging
import random
import time
import csv
import os

logger = logging.getLogger('state')

class MeterModel:
    def __init__(self, config, devices_data, data_lock, start_hour):
        self.config = config
        self.devices_data = devices_data
        self.data_lock = data_lock
        self.start_hour = start_hour
        if not devices_data or not data_lock:
            raise ValueError(f"Invalid initialization for {config.get('DeviceKey')}")
        self.total_power = 0.0

        # ── 频率相关参数 ──
        self.frequency_mode = config.get('frequency_mode', 0)
        self.nominal_frequency = config.get('nominal_frequency', 50.0)
        self.frequency_droop = config.get('frequency_droop', 0.001)
        self.frequency_noise = config.get('frequency_noise', 0.02)
        self.target_frequency = config.get('target_frequency', 50.0)
        self.frequency = self.nominal_frequency
        self.start_time = time.time()

        # 模式 3：CSV 回放
        self.frequency_curve = {}
        if self.frequency_mode == 3:
            csv_file = config.get('frequency_csv_file', '')
            if csv_file:
                self._load_frequency_curve(os.path.join('config', csv_file))

        logger.info(f"MeterModel initialized for {config.get('DeviceKey')}: "
                    f"frequency_mode={self.frequency_mode}, "
                    f"nominal={self.nominal_frequency} Hz")

    def _load_frequency_curve(self, filepath):
        """加载频率 CSV 曲线文件"""
        if not os.path.exists(filepath):
            logger.error(f"Frequency CSV file not found: {filepath}, "
                         f"falling back to mode 0 (droop)")
            self.frequency_mode = 0
            return
        self.frequency_curve = {}
        with open(filepath, 'r') as f:
            reader = csv.reader(f)
            next(reader, None)  # 跳过表头
            for row in reader:
                if len(row) >= 2:
                    try:
                        hour = float(row[0])
                        freq = float(row[1])
                        self.frequency_curve[hour] = freq
                    except ValueError:
                        logger.warning(f"Invalid row in frequency CSV: {row}")
        if not self.frequency_curve:
            logger.error(f"No valid data in frequency CSV, "
                         f"falling back to mode 0")
            self.frequency_mode = 0
        else:
            logger.info(f"Loaded frequency curve: "
                        f"{len(self.frequency_curve)} points")
```

```python
    def _interpolate_frequency(self, current_hour):
        """CSV 频率线性插值"""
        if not self.frequency_curve:
            return self.nominal_frequency
        times = sorted(self.frequency_curve.keys())
        current_hour = current_hour % 24
        if current_hour <= times[0]:
            return self.frequency_curve[times[0]]
        if current_hour >= times[-1]:
            return self.frequency_curve[times[-1]]
        for i in range(len(times) - 1):
            t1, t2 = times[i], times[i + 1]
            if t1 <= current_hour <= t2:
                f1 = self.frequency_curve[t1]
                f2 = self.frequency_curve[t2]
                return f1 + (f2 - f1) * (current_hour - t1) / (t2 - t1)
        return self.nominal_frequency

    def _calculate_frequency(self):
        """根据模式计算频率"""
        if self.frequency_mode == 0:
            # 模式 0：下垂模型
            deviation = -self.total_power * self.frequency_droop
            noise = random.uniform(-self.frequency_noise,
                                   self.frequency_noise)
            freq = self.nominal_frequency + deviation + noise
            return max(49.5, min(50.5, freq))

        elif self.frequency_mode == 1:
            # 模式 1：固定值 + 微小波动
            noise = random.uniform(-0.05, 0.05)
            return self.nominal_frequency + noise

        elif self.frequency_mode == 2:
            # 模式 2：可配置目标值（可通过 Modbus 写入更新）
            noise = random.uniform(-self.frequency_noise,
                                   self.frequency_noise)
            return self.target_frequency + noise

        elif self.frequency_mode == 3:
            # 模式 3：CSV 回放
            elapsed = time.time() - self.start_time
            current_hour = self.start_hour + (elapsed / 3600)
            return self._interpolate_frequency(current_hour % 24)

        else:
            return self.nominal_frequency
```

```python
    def update(self):
        """主更新循环（每秒调用一次）"""
        try:
            with self.data_lock:
                total_power = 0.0
                pv_power = 0.0
                load_power = 0.0
                for device_key, dev_info in self.devices_data.items():
                    if (dev_info.get('model') and 'data' in dev_info
                            and dev_info['data'].get(0) is not None):
                        active_power = dev_info['data'].get(0, 0)
                        if dev_info['type'] == 'PV':
                            pv_power += active_power
                        elif dev_info['type'] in ['Load', 'EV']:
                            load_power += active_power
                        elif dev_info['type'] == 'BESS':
                            if active_power > 0:
                                load_power += active_power
                            elif active_power < 0:
                                pv_power += abs(active_power)
                total_power = load_power - pv_power
                self.total_power = total_power

                # 模式 2：检查外部写入的频率设定值
                if self.frequency_mode == 2:
                    # 从共享数据中读取 FrequencySetpoint（寄存器偏移 4）
                    device_key = self.config.get('DeviceKey')
                    if device_key in self.devices_data:
                        setpoint = self.devices_data[device_key]['data'].get(4, None)
                        if setpoint is not None and setpoint > 0:
                            self.target_frequency = setpoint

        except Exception as e:
            logger.error(f"Error in MeterModel update: {str(e)}")
            self.total_power = 0.0

        # 计算频率
        self.frequency = self._calculate_frequency()

        logger.debug(f"MeterModel: Power={self.total_power:.2f} kW, "
                     f"Freq={self.frequency:.3f} Hz (mode={self.frequency_mode})")

        return {
            'ActivePower': self.total_power,
            'Frequency': self.frequency,
            'FrequencySetpoint': self.target_frequency
        }
```

## 10. 验证方案

### 10.1 分模式验证

| 模式 | 验证方法 | 预期结果 |
|------|---------|---------|
| 模式 0 | 启动仿真，增大负荷 | 频率下降；减小负荷，频率回升 |
| 模式 0 | ModbusPoll 读寄存器 2~3 | 值在 4950~5050 范围波动 |
| 模式 1 | 启动仿真，观察 1 分钟 | 频率稳定在 49.95~50.05 范围 |
| 模式 2 | FC16 写寄存器 4~5 为 4990（=49.9Hz） | 频率输出切换到 49.9 附近 |
| 模式 2 | REST API 写入 METER.FrequencySetpoint=51.0 | Go 下发 FC16，Python 频率切换到 51.0 |
| 模式 3 | 配置 CSV，启动仿真 | 频率按 CSV 数据时间线变化 |
| 模式 3 | CSV 不存在 | 自动回退模式 0，打印警告日志 |

### 10.3 边界验证

| 场景 | 预期 |
|------|------|

## 12. 风险与注意事项

| 风险 | 等级 | 应对措施 |
|------|------|---------|
| 模式切换需重启 | 低 | frequency_mode 在 __init__ 中读取，运行时不可切换（与 PV/Load 的 mode 一致） |
| 模式 2 写入竞争 | 低 | 仅单线程更新，data_lock 保护 |
| CSV 文件编码问题 | 低 | 使用 csv.reader 标准库，UTF-8/ASCII 均支持 |
| PyInstaller 打包遗忘 | 中 | build.sh 中已有源码时间戳检测逻辑 |
| 频率值超出正常范围 | 低 | 模式 0 有限幅；模式 3 原样输出（用户负责 CSV 数据质量） |
| gridsim-mcp 连带重编 | 低 | make dist 自动处理所有平台二进制 |
| 前端 TypeScript 编译 | 低 | vue-tsc 在 build 时自动类型检查 |
