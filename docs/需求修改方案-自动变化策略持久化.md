# 需求修改方案：自动变化策略持久化优化

## 问题描述

### 现象
用户在详情页配置了自动变化策略后，刷新页面或重新进入时，策略数据丢失。

### 根本原因

当前系统的数据持久化分层：

| 数据类型 | 存储位置 | 持久化状态 |
|---------|---------|-----------|
| 实例配置 | `config/instances.json` | ✅ 已持久化 |
| 点表文件 | `config/*.xlsx` | ✅ 已持久化 |
| 自动变化策略 | `config/auto_changes/{instance_id}.json` | ✅ 已持久化 |
| 实时测点值 | 内存 | ❌ 运行时数据 |
| 趋势面板配置 | 浏览器 `localStorage` | ⚠️ 仅本地浏览器 |

### 当前问题

1. **策略配置已持久化**：后端 `AutoChangeStore` 已将策略保存到 `config/auto_changes/{instance_id}.json`
2. **实例重启后策略未自动加载**：实例启动时未从持久化文件恢复策略
3. **前端缓存不一致**：浏览器 localStorage 中的策略数据与服务端可能不同步

```typescript
  if (!instanceId.value) return  // 防御性检查：instanceId 为空时直接返回
  try {
    const res = await getPoints(instanceId.value)
    // ...
  }
}
```

### 2. 待实现：实例启动时自动加载策略

#### 当前流程

```
实例启动 → 创建引擎 → 策略引擎初始化（空策略）
```

#### 目标流程

```
实例启动 → 创建引擎 → 加载持久化策略文件 → 恢复策略配置 → 启动策略引擎
```

#### 涉及文件

| 文件 | 修改内容 |
|-----|---------|
| `internal/manager/manager.go` | `startMicrogrid()` 中增加策略加载逻辑 |
| `internal/detail/engine.go` | `NewEngine()` 或 `LoadAndStart()` 支持加载已保存策略 |

#### 伪代码

```go
// manager.go - startMicrogrid()
func (m *Manager) startMicrogrid(cfg *model.InstanceConfig) error {
    // 1. 创建引擎
    engine := detail.NewEngine(...)
    
    // 2. 加载持久化的策略配置
    savedConfigs, err := m.autoChangeStore.Load(cfg.ID)
    if err == nil && len(savedConfigs) > 0 {
        for ioa, config := range savedConfigs {
            engine.StartOrUpdate(ioa, config)
        }
    }
    
    // 3. 启动引擎
    engine.Start()
    // ...
}
```

### 3. 待实现：前端策略缓存同步

#### 当前问题

- 用户在浏览器 A 配置策略
- 在浏览器 B 访问时看不到已配置的策略
- 或者浏览器清除缓存后策略丢失

#### 解决方案

**方案 A：页面加载时从服务端拉取已保存策略**（推荐）

```typescript
// DetailPage.vue - onMounted
onMounted(async () => {
  if (!instanceId.value) return
  
  // 从服务端加载已持久化的策略
  try {
    const configs = await getAutoChanges(instanceId.value)
    // 合并到本地 autoStrategies
    for (const cfg of configs) {
      autoStrategies[cfg.ioa] = cfgToCode(cfg)
    }
  } catch (e) {
    console.error('加载策略失败:', e)
  }
  
  // 继续原有逻辑...
})
```

**方案 B：策略配置完全由服务端管理**

- 前端不再维护 `autoStrategies` 本地状态
- 所有策略操作直接调用 API
- 页面渲染从 API 返回数据

### 4. 待实现：策略导入导出优化

#### 当前功能

- 导出：`GET /api/v1/instances/{id}/auto-changes/export` → JSON 文件
- 导入：`POST /api/v1/instances/{id}/auto-changes/import` ← JSON 文件

#### 优化方向

1. **导出格式增强**
   - 添加导出时间戳
   - 包含实例元信息（名称、协议、端口）
   - 支持 CSV 格式（已在 `downloadCSV` 中部分实现）

2. **导入校验增强**
   - 校验文件格式版本
   - 校验 IOA 是否存在于当前实例
   - 提供冲突处理选项（覆盖/跳过/合并）

## 测试验证

### 验证步骤

1. **策略持久化验证**
   - 启动实例
   - 配置自动变化策略
   - 停止实例
   - 重新启动实例
   - 验证策略是否恢复

2. **跨浏览器验证**
   - 在浏览器 A 配置策略
   - 在浏览器 B 打开同一实例详情页
   - 验证策略是否显示

3. **异常场景验证**
   - 直接访问 `/detail` 或 `/detail/`
   - 验证不会发起无效 API 请求
   - 页面应显示错误提示或重定向
