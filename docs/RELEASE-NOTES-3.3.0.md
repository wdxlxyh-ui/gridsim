# GridSim 3.3.0 发布说明

- 发布日期：2026-08-15
- 标签：`v3.3.0`
- 分支：`main`

## 发布摘要

GridSim 3.3.0 增加每实例时序持久化、实时与历史趋势分离、停止实例点表上传替换与协议校验，并修复 Modbus TCP 控制兼容性问题。发行包继续包含 Linux amd64、Linux arm64 与 Windows amd64 三个平台产物。

## 新增功能

### 每实例时序持久化

- 使用 SQLite 保存每个运行实例最近 60 分钟的时序数据。
- 默认周期采样间隔为 1 秒。
- AI、DI、PI 每秒写入周期样本；值变化后立即异步入队。
- AO、DO 不参与周期采样，仅在控制或写入操作发生时记录；同值重复控制会保留审计记录。
- 提供数据库状态、历史查询和最新持久化快照接口，趋势页面可直接使用。

### 趋势页面

- 实时趋势与固定时间范围历史查询分离。
- 实时曲线按接口返回的 `updated_at` 展示，不再将浏览器轮询时间作为样本时间。
- 未变化的 AO、DO 不会因页面刷新被绘制为新的当前样本。
- 保留曲线重置、批量读取、CSV 导出和多测点对比能力。

### 停止实例点表替换

- 「配置管理」中的「编辑点表」弹窗新增「上传并替换」入口。
- 仅允许对停止实例执行替换，上传文件仅支持 `.xlsx`，最大 10 MB。
- 系统先校验再替换；任何解析或协议校验失败都不会修改原点表。
- 替换前自动备份原文件到 `config/point-table-backups/<实例ID>/`。
- 替换后重新启动实例，新点表生效。

### 点表校验

- 通用：校验 `point` 工作表、数据行、点类型、IOA 格式和同类型 IOA 重复。
- IEC104 / IEC104 Client：校验 IOA 不超过 3 字节上限 `16777215`。
- Modbus TCP：校验功能码、寄存器地址、地址边界与 32 位数据寄存器区间重叠。

### Modbus TCP 修复

- 修复 FC5 单线圈写响应。
- 修复 DO 状态显示同步。
- 改进 FC16 多寄存器写入与既有地址映射的处理。

## 升级说明

1. 停止 GridSim 服务并备份现有 `config/` 目录。
2. 使用对应平台的 `v3.3.0` 发行包替换程序、Web 静态资源和内置资源。
3. 恢复原 `config/` 目录，保留 `instances.json`、点表、数据库、用户和自动变化策略。
4. 启动服务后，按原运行状态启动所需实例。
5. 浏览器使用强制刷新重新加载 Web 静态资源。

现有实例配置和点表格式无需迁移。首次启动持久化功能后，数据库会开始收集新的保留窗口数据。
