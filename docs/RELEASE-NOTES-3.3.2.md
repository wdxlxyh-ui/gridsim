# GridSim v3.3.2 发布说明

- 标签：`v3.3.2`
- 日期：2026-08-15

## 趋势看板类型隔离

- 趋势页将测点划分为三类互斥看板：采集趋势（AI、DI、PI）、AO 控制和 DO 控制。
- AI、PI 不再与 AO 共享数值 Y 轴，避免 AO 大量程设定值压缩采集曲线。
- AO 保持阶梯状态曲线和菱形控制事件；DO 保持固定 0～1 阶梯状态和圆形控制事件。
- 混合选择测点时，系统按测点类型自动分流到兼容看板；不再允许 AI/DI/PI、AO、DO 混在同一看板。
- 实例详情页的单点和多点趋势入口会保留测点类型，并自动进入正确看板。

## 模板兼容

- 趋势模板改为保存完整看板结构和测点类型，不再将多个看板扁平化后恢复到同一个面板。
- 可识别类型的旧本地看板和旧模板会在加载时自动拆分；无法识别的旧测点不会被随意归类。
