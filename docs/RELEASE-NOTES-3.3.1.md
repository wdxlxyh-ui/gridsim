# GridSim 3.3.1 发布说明

- 标签：`v3.3.1`
- 日期：2026-08-15

## 趋势与控制事件

- AO 使用阶梯状态曲线，并以菱形标记每次控制写入；同值重复控制仍可见。
- DO 使用独立 0～1 状态轨道，并以圆点标记每次控制写入。
- DI 使用独立二值状态轨道，避免被 AO 数值量级压缩。
- 历史查询显示后端实际返回的时间范围；当请求早于保留窗口时，显示截断状态和保留期。

## 历史数据管理

- 历史查询页支持按实例选择有持久化记录的测点。
- 清理操作只删除选定 IOA 的历史样本，要求二次确认和 `confirm=true`。
- 不支持空选择或整实例、整库删除；单次最多 500 个测点。
- 运行中的 AI、DI、PI 会在后续采样周期写入新的样本。

## 持久化默认值

- SQLite 历史默认保留期从 60 分钟调整为 1440 分钟（1 天）。
- `--db-retention-minutes` 支持范围为 1～10080 分钟。
