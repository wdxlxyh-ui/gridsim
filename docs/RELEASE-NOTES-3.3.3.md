# GridSim v3.3.3 发布说明

- 标签：`v3.3.3`
- 日期：2026-08-15

## 趋势工作台 UI 重设计

- 实时趋势与历史查询改为工业控制台式工作区，集中展示数据视图、查询范围、模板、布局和面板概览。
- 趋势面板增加采样状态、历史范围、刷新间隔、暂停和重新采样等可见反馈。
- 图表底部的内置图例替换为曲线清单，显示曲线颜色、实例、点类型和单位；支持单曲线显示/隐藏、悬停聚焦和快速移除。
- 采集趋势、AO 控制和 DO 控制面板沿用独立的视觉标识与数据类型隔离规则。
- 补充 `trend-ui-demo.html`，可直接在浏览器中预览趋势工作台的界面结构和交互状态。

## 性能与可用性

- 保持 Canvas 渲染、无动画实时更新和批量读取策略。
- 稠密的非控制历史曲线按需启用 LTTB 采样和大数据渲染；AO、DO 控制事件不采样，继续完整保留每次控制写入。
- 优化窄屏布局、键盘焦点可见性，并遵循减少动态效果的系统设置。
