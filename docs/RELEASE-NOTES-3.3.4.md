# GridSim v3.3.4 发布说明

- 标签：`v3.3.4`
- 日期：2026-08-15

## 趋势拖拽稳定性

- 修复实时趋势在拖拽、缩放时可能出现旧曲线残留或局部未重绘的问题。
- ECharts 使用稳定的 Canvas 完整重绘；拖拽期间实时样本仍持续读取和缓存，鼠标释放后统一刷新图表。
- 保留批量读取、无动画更新和稠密 AI/PI 曲线采样策略；AO、DO 写入记录仍完整保留。

## AO / DO 控制趋势文案

- AO 明确显示「当前设定值」和「每次写入」：阶梯线表示保持的设定值，菱形表示每次写入。
- DO 明确显示「当前开关状态」和「每次写入」：阶梯线表示保持的开关状态，圆点表示每次写入。
- 面板标签、图内标题和提示框统一使用「写入记录」，避免将控制写入误解为告警事件。
