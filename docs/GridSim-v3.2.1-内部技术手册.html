1. 产品概述

GridSim 是一款多协议电力系统仿真工具，主要用于：

  • 电力 SCADA/EMS 系统的联调测试
  • Modbus TCP 设备仿真
  • 微电网场景（光伏、储能、充电桩、负荷）物理模型仿真
  • IEC104 主站/从站模式测试
  • Python 微电网多实例并行仿真

1.1 支持的协议类型

协议说明
IEC104标准 IEC 60870-5-104 从站模式，响应总召、变化上送、AO/DO 控制
IEC104 客户端主站模式，连接远端从站，接收遥测/遥信，发送遥控/遥调
Modbus TCPModbus TCP 从站，支持 FC01~06、0F、10 功能码
微电网Go 原生微电网物理模型仿真（拓扑编辑器）
Python 微电网基于 Python 物理模型的多实例仿真（PV/BESS/EV/Load/Meter），支持 EnOS 点表导出

1.2 系统架构

此处插入截图: 系统架构图

Go 主程序管理多个协议实例。Python 微电网实例通过独立进程运行，Go 通过 Modbus TCP 轮询采集数据展示在 Web UI。每个实例拥有独立端口、工作目录和日志。外部 EMS 可同时连接读取数据。

2. 部署指南

2.1 系统要求

项目要求
操作系统Linux (amd64/arm64) 或 Windows (amd64)
内存≥ 512MB
磁盘≥ 100MB
端口8989（Web）+ 各实例协议端口
Python3.8+（仅 Python 微电网需要）

2.2 一键部署（推荐）

使用自解压安装包，仅需一个文件：

bash gridsim-install-v3.2.1-linux-amd64.sh

自动完成：停止旧服务 → 备份配置 → 解压 → 恢复配置 → 注册 systemd → 启动 → 健康检查。

参数说明
--target <目录>指定部署目录（默认 /home/envuser/IEC/gridsim）
--status查看当前服务状态
--stop / --start / --restart服务控制

2.3 手动部署

# Linux
tar xzf gridsim-v3.2.1-linux-amd64.tar.gz
cd gridsim-v3.2.1-linux-amd64/
./bin/start.sh

# Windows
解压 zip → 双击 bin/gridsim.exe

2.4 启动与停止

操作命令
启动./bin/start.sh 或 systemctl start gridsim
停止./bin/stop.sh 或 systemctl stop gridsim
重启./bin/restart.sh
查看日志tail -f logs/output.log

启动后浏览器访问: http://<服务器IP>:8989，默认账号 admin / admin123

4. Python 微电网实例

4.1 概述

每个 Python 微电网实例独立运行一个 Python 进程，通过 Modbus TCP 暴露设备数据。支持多实例并行：

  • 独立 Modbus TCP 端口（5021、5022、5023...）
  • 独立工作目录、设备配置、日志
  • 外部 EMS 可直接通过 Modbus TCP 连接（多客户端支持）
设备类型功能
Meter 电表自动汇总全站功率（固定 1 台）
PV 光伏正弦曲线或 CSV 回放，支持限功率控制
BESS 储能SOC 充放电计算、功率指令响应
EV 充电桩AC/DC 双模式、定时充电调度
Load 负荷CSV 曲线回放或随机波动

4.2 创建实例

  1. Web UI → "配置管理" → "添加实例"
  2. 规约类型选择"Python微电网"
  3. 填写实例名称
  4. 配置 Modbus 端口（多实例不能重复，系统自动检测冲突）
  5. 配置轮询间隔（推荐 1000ms）和仿真起始时间（HH:MM）
  6. 确认创建，实例为"已停止"状态

4.3 设备配置

点击"Python仿真"按钮 → "配置管理" tab。

4.3.1 PV 光伏

参数说明默认值
DeviceKey唯一标识必填
ratedPower额定功率 kW必填
mode0=CSV, 1=正弦1
slave_idModbus 从站地址自动分配

正弦模式：6:00~18:00 按 sin²(x) 出力。CSV 模式：15 分钟步长，线性插值。

4.3.2 BESS 储能

参数说明默认值
ratedCapacity容量 kWh200
maxChargePower最大充电 kW100
maxDischargePower最大放电 kW100
initial_soc初始 SOC (0~1)0.5

通过 BS.SysAPSetPoint 下发功率指令，正值放电，负值充电。

4.3.3 EV 充电桩

参数说明默认值
PUB_CONN.RatedPW额定功率 kW必填
charger_typeAC/DCAC
charge_schedule充电时段[{8:00-10:00}]

4.3.4 Load 负荷

参数说明默认值
base_power基础功率 kW120
mode0=CSV, 1=随机±20%0

4.3.5 Meter 电表

固定 1 台，自动汇总：并网功率 = 负荷 + 充电桩 − 光伏 − 储能放电 + 储能充电

4.4 启动运行

确保配置了至少 1 个设备 → 点击"启动"。系统自动创建隔离工作目录、启动 Python 进程、等待端口就绪。

修改配置需先停止实例 → 修改 → 重新启动。

4.6 导出 EnOS 点表

运行中点击"导出点表" → 下载 zip 包（每设备一个 xlsx）。

coefficient0.01

4.8 故障排查

问题解决
启动超时 "timeout waiting for port"检查 py_instances/<id>/log/ 日志
端口冲突修改 Modbus 端口（不能重复）
PV 功率为 0修改仿真起始时间到白天时段
外部无法连接iptables -I INPUT 1 -p tcp --dport <端口> -j ACCEPT
